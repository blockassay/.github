# BlockAssay — blockchain evidence intelligence

BlockAssay helps you check a token or a public wallet address **before you trust it**.
Every observation comes with its **source and the time it was checked**. What could not be verified is shown as *unknown* — never as safe.

## What you can check

- **Radar** — on-chain facts for covered tokens: mint authority, freeze authority, top-10 holder share, observed liquidity. Each fact links to its evidence page.
- **Wallet Intelligence** — paste a public address (EVM, Solana, Bitcoin). No wallet connection, no signature, no seed phrase. A free account is required for a full analysis.
- **Guides** — step-by-step methods: how to verify a token, spot a risky token, detect a token bundle.

## Principles

- Evidence first: source + UTC timestamp for every fact.
- Unknown ≠ safe.
- No custody, no trading, no financial advice.
